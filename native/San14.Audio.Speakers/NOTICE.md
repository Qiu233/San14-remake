San14.Audio.Speakers is project-owned source compiled for Windows x64. It implements only the Godot AudioEffectInstance speaker-pair gate.

The included gdextension_interface.h is from Godot4.4-stable, https://github.com/godotengine/godot/blob/4.4-stable/core/extension/gdextension_interface.h , SHA256 recorded in the private acquisition manifest. The interface is compatible with Godot4.3 or newer for the functions used by this bridge.
